📸 Responsive Image Gallery

A modern, responsive image gallery built using HTML, CSS, and JavaScript as part of my Code Alpha Internship Project.

The gallery features an attractive layout, smooth hover animations, interactive image previews, and category-based filtering for a better user experience.

✨ Features
Responsive Design: Works on desktop, tablet, and mobile devices.
Interactive Lightbox: Click any image to view it in a larger preview.
Next & Previous Navigation: Easily browse through gallery images.
Category Filters: Filter images by Nature, Animals, and Architecture.
Hover Effects: Smooth zoom animations and image overlays.
Keyboard Navigation: Use the arrow keys to navigate and Escape to close the lightbox.
Modern UI: Clean layout with smooth transitions and attractive styling.
Accessibility: Includes image descriptions and keyboard interaction support.
🛠️ Technologies Used
HTML5 – For the structure and layout.
CSS3 – For styling, animations, hover effects, and responsive design.
JavaScript – For image navigation, lightbox functionality, and category filtering.
